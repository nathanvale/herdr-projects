# Issue tracker: GitHub

New engineering-skill issues and specs live in GitHub Issues.

Resolve the target repository from the selected Git remote and scope
operations explicitly to it. When fork and upstream remotes coexist,
do not silently switch between them. Use the GitHub CLI through any
environment-required wrapper.

"Publish to the issue tracker" means create an issue.
"Fetch the relevant ticket" means read its body, labels and comments.

Keep existing Shepherdr tasks in their current owner. This setup does
not migrate, duplicate or change their dependencies.

PRs as a request surface: no.
