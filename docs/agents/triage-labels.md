# Triage labels

Use these exact labels for the corresponding roles.

| Role and label | Meaning |
| --- | --- |
| needs-triage | Needs maintainer evaluation |
| needs-info | Waiting for reporter information |
| ready-for-agent | Fully specified for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

This configuration does not itself create labels in GitHub.
